## 六、关键数据洞察总结

**关于缺失值：**
- ID/Label/时间：**零缺失**，是最可靠的训练信号
- 用户 int 特征 `_83`–`_103` 系列：**缺失率 50–91%**，属于高稀疏用户画像，建模时需特别处理
- `item_int_feats_83/84/85`：**83.2% 缺失**，仅特定内容类型（约17%内容）有这三个属性

**关于标签分布：**
- label_type 严重不平衡（**7:1**，876 vs 124），label=2 是正样本（用户感兴趣），实际训练需要考虑采样或加权

**关于域序列长度：**
- 四个域历史长度差异显著（均值：domain_d > domain_a > domain_b > domain_c）
- 最长历史达3951条，体现出用户在不同场景的活跃度分布差异

**关于特征结构的整体模式：**
序列内多列特征是**"事件级 side-info"模式**——每个交互事件都携带时间戳、内容ID、行为类型、内容属性等多维侧信息，这是工业级推荐系统中常见的多值特征表示方式。
