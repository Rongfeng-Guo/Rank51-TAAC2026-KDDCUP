针对 50–91% 缺失率的高稀疏用户画像特征，有以下几类处理策略，按推荐优先级排列：

---

## 1. 缺失本身作为信息（最推荐）

缺失不等于"无信息"——**用户没有这个属性本身就是一种用户特征**（如未填写学历 = 可能是冷启用户）。

做法：为每个高缺失特征增加一个 `is_missing` 的 0/1 指示列，和原列一起输入模型。

```python
for col in high_missing_cols:
    df[f"{col}_is_missing"] = df[col].isna().astype(int)
    df[col] = df[col].fillna(0)  # 缺失填0，用指示列区分
```

好处：MLP 可以学到"有值 vs 无值"的差异，不丢弃信息。

---

## 2. 填充策略（按特征语义选择）

| 特征类型 | 推荐填充方式 |
|---|---|
| 分类 ID（如职业、学历） | 填充一个专用 `UNKNOWN` 类别码（如 -1 或 0） |
| 等级/档位（如 `_104`–`_109` 值域 1–3） | 填充众数或中位数 |
| 二值 flag（`_100`、`_107`） | 填充 0（表示"否/未知"） |

**不推荐**用均值填充，因为这些特征是离散 ID 类型，均值无语义。

---

## 3. 嵌入层处理（适合 Embedding 模型）

对于离散 ID 类型的特征，使用 Embedding 层时可以把 0 作为 padding token，让模型自己学习"缺失"的表示：

```python
# 0 = 缺失/padding，实际 ID 从 1 开始
embedding = nn.Embedding(num_categories + 1, embed_dim, padding_idx=0)
```

---

## 4. 特征分组建模（减小稀疏影响）

把 120 列特征按缺失率分层，训练时对不同组给予不同权重或独立处理路径：

- **全量特征组**（缺失 < 5%）：直接输入主干网络
- **中等稀疏组**（5–50%）：填充 + 指示列
- **高稀疏组**（> 50%）：单独走一个轻量子网络，缺失时输出零向量，避免噪声传播

```
输入
 ├── 全量特征 → Dense Tower
 ├── 中稀疏特征 + mask → Dense Tower
 └── 高稀疏特征 → 稀疏子网络（可选）
        ↓
      concat → 分类器
```

---

## 5. 不要直接丢弃这些列

虽然缺失率高，但当特征**存在时**往往是强信号（比如 `_99`：缺失 81%，但有值的用户可能有明确的行为偏好）。直接丢弃会损失这部分强用户的精度。
